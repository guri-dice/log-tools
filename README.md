# TRPG 로그 변환기

코코포리아, Roll20 로그를 티스토리 등 블로그에 올리기 좋게 바꿔 주는 도구입니다.
로그 파일은 서버로 전송되지 않고 브라우저 안에서 처리됩니다.

## 바로 쓰기

| 변환기 | 링크 | 버전 | 수정일 |
|---|---|---|---|
|  CoC  | [열기](https://guri-dice.github.io/log-tools/CoC.html) | v1.0 | 2026-11-04 |
| 인세인 | [열기](https://guri-dice.github.io/log-tools/insane.html) | v1.0 | 2026-11-04 |

## 사용법

1. 위 링크에서 변환기를 엽니다.
2. 로그 파일을 열거나 끌어다 놓습니다.
3. 디자인을 고르고 미리보기를 확인합니다.
4. 코드를 복사해 블로그의 HTML 모드에 붙여 넣습니다.

## 참고

- 작업 내용은 사용 중인 브라우저에 자동 저장됩니다.
- PC 사용을 권장합니다.

# TRPG 로그 변환기

개인적으로 사용하기 위해 Claude Opus 5.5를 사용하여 만든 변환기입니다.  
문의는 너구리(@babo_wja)에게 주시면 감사하겠습니다.  
링크가 있는 분에 한해 자유롭게 사용하실 수 있습니다. 개인 맞춤형으로 재 수정하셔도 됩니다. (real)  

코코포리아, Roll20 로그를 블로그에 올리기 좋게 변환합니다.  
로그 파일은 서버로 전송되지 않고 브라우저 안에서 처리되며, 작업 내용은 사용 중인 브라우저에 자동 저장됩니다.  
  
PC 사용을 권장합니다.

**[변환기 바로 가기](https://guri-dice.github.io/log-tools/)**

## 변환기 목록

| 변환기 | 설명 | 링크 | 버전 | 수정일 |
|---|---|---|---|---|
| CoC | CoC 세션 로그를 변환하고 화자별 색과 주사위 결과 표시를 정리합니다. | [열기](https://guri-dice.github.io/log-tools/CoC.html) | v1.0 | 2026-11-04 |
| 인세인 | 인세인 세션 전용으로, 판정 표시와 비밀 접기, 장면 종료 표시를 지원합니다. | [열기](https://guri-dice.github.io/log-tools/insane.html) | v1.0 | 2026-11-04 |

## 사용법

1. 사용할 변환기를 선택합니다.
2. 로그 파일을 열거나 끌어다 놓습니다.
3. 디자인을 선택하고 미리보기를 확인합니다.
4. 코드를 복사하여 블로그의 HTML 모드에 붙여 넣습니다.

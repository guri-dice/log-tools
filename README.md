# TRPG 로그 변환기

코코포리아, Roll20 로그를 블로그에 올리기 좋게 변환합니다.
로그 파일은 서버로 전송되지 않고 브라우저 안에서 처리됩니다.

**[변환기 바로 가기](https://guri-dice.github.io/log-tools/)**

## 변환기 목록

| 변환기 | 설명 | 링크 | 버전 | 수정일 |
|---|---|---|---|---|
| CoC | CoC 세션 로그를 변환합니다. 화자별 색과 주사위 결과 표시를 정리할 수 있습니다. | [열기](https://guri-dice.github.io/log-tools/CoC.html) | v1.0 | 2026-11-04 |
| 인세인 | 인세인 세션 전용입니다. 인세인 판정 표시와 비밀 접기, 장면 종료 표시를 지원합니다. | [열기](https://guri-dice.github.io/log-tools/insane.html) | v1.0 | 2026-11-04 |

## 사용법

1. 사용할 변환기를 선택합니다.
2. 로그 파일을 열거나 끌어다 놓습니다.
3. 디자인을 선택하고 미리보기를 확인합니다.
4. 코드를 복사하여 블로그의 HTML 모드에 붙여 넣습니다.

## 참고

- 작업 내용은 사용 중인 브라우저에 자동 저장됩니다.
- PC 사용을 권장합니다.

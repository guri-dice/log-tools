TRPG 로그 변환기

설정

1. 로그 열기
예시 로그예시 로그를 표시하고 있습니다

코코포리아 로그 HTML · Roll20 채팅 기록 · 저장해 둔 작업 파일(.json)을 자동으로 인식합니다. 파일을 끌어다 놓아도 됩니다.

작업 내용은 이 브라우저에 자동 저장됩니다
Roll20 기록 받는 법

채팅창 위 톱니바퀴 → Show Archive → 맨 아래까지 스크롤 → 브라우저 다른 이름으로 저장 → 웹페이지, 전체.

캐릭터 얼굴까지 살리려면 로그 파일 열기에서 .html 파일과, 같이 생긴 _files 폴더 안의 그림들을 함께 선택하십시오(PC에서 Ctrl+A). imgur에 올린 그림은 폴더 없이도 원래 주소로 표시됩니다.

2. 디자인

글자색은 선택한 디자인을 따릅니다. 블로그 배경이 밝으면 흰색·Roll20, 어두우면 다크·코코포리아를 권장합니다.

3. 붙여넣기

화면 아래 티스토리용 코드 복사 → 티스토리 글쓰기 기본모드 ▾ → HTML → 붙여넣기 → 발행. 어떤 스킨에서도 미리보기와 동일하게 표시됩니다.
